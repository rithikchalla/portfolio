# Rithik Reddy Challa · Portfolio

Animated, dependency-free portfolio site for a data engineering job search: canvas data-packet background, typewriter hero, ETL pipeline diagram, filterable skills, tilting project cards and a typed terminal.

- Live (after enabling Pages): https://rithikchalla.github.io/portfolio/
- Edit content in `assets/data.js`. Nothing else needs to change.
- Run locally: open `index.html`, or `python3 -m http.server`.
- Deploys with GitHub Pages via `.github/workflows/pages.yml` (Settings → Pages → Source: GitHub Actions).
